# K.AI — Консольный AI-ассистент для Windows

Модульный консольный ассистент для Windows с локальной нейросетью Ollama (`qwen2.5:3b-instruct`), встроенной долговременной памятью (`memory.json`), системой обучения привычкам и резервным Regex-парсером при отключенной модели.

---

## 📁 Архитектура проекта и назначение файлов

```text
k-ai/
├── kai/                          # Основной пакет логики ассистента
│   ├── __init__.py               # Публичный API пакета и удобный реэкспорт функций
│   ├── app.py                    # Главный цикл диалога (process_query, REPL-цикл main)
│   ├── config.py                 # Загрузка и сохранение config.json и memory.json
│   ├── constants.py              # Белый список ALLOWED_ACTIONS, KNOWN_APPS, дефолты
│   │
│   ├── core/                     # Ядро понимания естественного языка (NLU)
│   │   ├── __init__.py           # Экспорт модулей ядра
│   │   ├── ollama.py             # Клиент Ollama, автозапуск сервера, промпты, CJK-фильтр
│   │   └── fallback.py           # Запасной Regex-парсер и удаление префиксов ('K.AI, ...')
│   │
│   ├── actions/                  # Модули выполнения действий (белый список)
│   │   ├── __init__.py           # Экспорт всех обработчиков действий
│   │   ├── dispatcher.py         # Единый диспетчер и валидация команд по белому списку
│   │   ├── apps.py               # Запуск Telegram, WhatsApp и любых Windows-приложений
│   │   ├── browser.py            # Открытие последнего видео YouTube из истории и сайтов/URL
│   │   ├── ide.py                # Поиск и открытие последнего проекта в VS Code / IDE
│   │   ├── files.py              # Файловые операции (mkdir, list, copy, move, delete)
│   │   ├── system.py             # Системные функции (громкость, блокировка, сон, буфер)
│   │   ├── memory.py             # Запоминание («запомни, что ... это ...») и воспоминания
│   │   ├── timer.py              # Неблокирующий таймер со звуковым сигналом winsound
│   │   └── chat.py               # Свободный диалог и ответы на вопросы
│   │
│   └── utils/                    # Низкоуровневые утилиты Windows
│       ├── __init__.py           # Экспорт утилит
│       └── platform.py           # WinAPI заголовок консоли, UTF-8 кодировка, медиа-клавиши
│
├── kai.py                        # Точка входа для запуска в Python и сборки PyInstaller
├── test_kai.py                   # Автоматические модульные и интеграционные тесты (16 тестов)
├── config.json                   # Пользовательские настройки (модель, пути, алиасы)
├── memory.json                   # Долговременная память ассистента (алиасы и привычки)
├── requirements.txt              # Зависимости проекта (requests, pyinstaller)
├── kai.spec                      # Спецификация сборки PyInstaller
└── dist/
    ├── kai.exe                   # Готовый переносимый исполняемый файл
    └── config.json               # Конфигурация рядом с исполняемым файлом
```

## 🛠 Описание модулей

| Модуль / Каталог | За что отвечает |
| :--- | :--- |
| **`kai.py`** | Входной скрипт. Обеспечивает запуск `kai.app.main()` и совместимость при сборке в один `kai.exe`. |
| **`kai/app.py`** | Консольный интерфейс: заголовок окна `SetConsoleTitleW`, цикл чтения команд, перехват прерываний, маршрутизация в диспетчер. |
| **`kai/config.py`** | Чтение/запись `config.json` и `memory.json`, определение пути к приложению (`frozen` / исходники). |
| **`kai/constants.py`** | Конфигурация по умолчанию, список известных приложений (`notepad`, `calc`, `spotify` и др.), белый список действий. |
| **`kai/core/ollama.py`** | Фоновый автозапуск `ollama serve` (без всплывающих окон через `CREATE_NO_WINDOW`), генерация строгого системного промпта, вызов `/api/chat`, фильтрация языка ответа. |
| **`kai/core/fallback.py`** | Резервный разбор по регулярным выражениям при недоступности Ollama, очистка обращения («K.AI, ...»). |
| **`kai/actions/dispatcher.py`** | Защитный барьер: проверка `action in ALLOWED_ACTIONS`, исключение произвольного выполнения шелл-команд, вызов специализированных функций. |
| **`kai/actions/apps.py`** | Запуск протоколов `tg://`, `whatsapp://` с откатом в браузер, а также запуск любых Windows-программ по названию. |
| **`kai/actions/browser.py`** | Безопасное чтение истории Chrome/Edge через временную SQLite копию, открытие последнего видео YouTube и сайтов по алиасам. |
| **`kai/actions/ide.py`** | Чтение последнего проекта из `%APPDATA%\Code\User\globalStorage\storage.json` или `config.json`. |
| **`kai/actions/files.py`** | Безопасная работа с файловой системой: просмотр, создание папок, копирование; деструктивные операции (`delete`, `move`, `rename`) требуют явного подтверждения (`[y/N]`). |
| **`kai/actions/system.py`** | Управление Windows: мультимедиа-клавиши громкости, выключение звука, блокировка экрана, буфер обмена. |
| **`kai/actions/memory.py`** | Обучение: сохранение пар ключ-значение в `memory.json` и их воспроизведение по запросу («что ты запомнил?»). |
| **`kai/actions/timer.py`** | Запуск таймера в отдельном `threading.Thread` со звуковым оповещением `winsound.Beep`. |
| **`kai/actions/chat.py`** | Вывод реплик свободного общения и ответов на вопросы пользователя на русском языке. |
| **`kai/utils/platform.py`** | Настройка кодировки консоли UTF-8, вызовы WinAPI функций клавиатуры и заголовочной строки. |

## 🚀 Запуск и сборка

### 1. Установка зависимостей
```powershell
pip install -r requirements.txt
```

### 2. Запуск из исходников
```powershell
python kai.py
```

### 3. Запуск тестов
```powershell
python -m unittest test_kai.py
```

### 4. Сборка в один файл `kai.exe`
```powershell
pyinstaller --onefile --name kai kai.py
```
Готовый исполняемый файл создаётся в папке `dist/kai.exe`.

- **Общение:** `привет`, `как дела?`, `кто ты?`, `что ты умеешь?`
- **Обучение и память:** `запомни, что работа это открыть VS Code и гитхаб`, `что ты запомнил?`

- **Система:** `увеличь громкость`, `выключи звук`, `заблокируй экран`
- **Таймер:** `поставь таймер на 15 секунд`, `таймер полчаса`, `засеки 5 минут пицца`
- **Разработка:** `открой проект в ide`, `открой гитхаб`
- **Медиа:** `открой последнее видео на ютубе`
- **Файлы:** `покажи файлы`, `создай папку C:\test`
- **Выход:** `выход`, `пока`
